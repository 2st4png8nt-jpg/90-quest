# 90 Day Quest

A habit-stacking RPG. Pick a goal, get a 90-day plan, earn XP, and unlock bite-sized lore from Pip explaining the real research behind each day.

- `app/` — the Expo (React Native) app for iOS and Android
- `research/sources.json` — every study the in-app lore cites, each verified
- `docs/DECISIONS.md` — product decisions and the rules taken from the research
- `preview/index.html` — the original single-page web prototype
